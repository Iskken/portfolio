# Data Scientist Portfolio

A polished dark-first personal portfolio for a computer science student and aspiring data scientist. Built with Next.js App Router, TypeScript, Tailwind CSS, shadcn-style UI primitives, lucide-react icons, and subtle framer-motion animations.

## Tech Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS 4
- shadcn/ui-compatible reusable components
- lucide-react
- framer-motion

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available Scripts

```bash
npm run dev
npm run build
npm run lint
npm run start
```

## Project Structure

```text
src/
  app/
    globals.css
    layout.tsx
    page.tsx
  components/
    animations/
    layout/
    sections/
    shared/
    ui/
  lib/
    data.ts
    utils.ts
```

Portfolio content is centralized in `src/lib/data.ts`. Replace placeholder names, links, project URLs, and contact details there first.
